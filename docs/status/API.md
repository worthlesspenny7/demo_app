# Core engine API (stable surface for UI and agents) - keep in sync with src/core/sim.ts

```ts
import { Simulator, type Action, type Observation, type StageResult } from './core/sim.js';
const sim = new Simulator(scenario, { watch: 'analog' | 'digital', useCard?: boolean });
sim.step(dtSeconds);     // integrates in fixed 0.1 s ticks; safe to pass any dt
sim.observe();           // Observation: what the navigator can see (no hidden positions)
sim.act(action);         // Action union: watch.*, bezel.set, call.speed/turn/stop/go/uturn/pass/pullover,
                         //   line.set, note, ta.declare, speedo.setFactor, card.set, start, skipPreread
sim.phase;               // 'preread' | 'running' | 'finished'
sim.result();            // StageResult: score (legs, raw, ageFactor, score, aces), records, attribution, events
sim.pace();              // TRUTH: seconds late(+)/early(-) now; UI may show only when aids.paceBar
```
Scenarios: `ScenarioBuilder` in src/core/builder.ts (start/stop/speedAtSign/timedAt/checkpoint/restart/finish/hazard).
Ghost: `buildGhost(scenario)`, `ghostTimeAt(table, s)` (truth; debrief only).
Perf table: `stopLoss(vIn,vOut,car)`, `accelLoss(vOut,car)`, `rampLead(v1,v2,car)`, `dwellFor(pause,vIn,vOut,car)`, `buildPerfTable(car)`.
Drills: `src/core/drills/types.ts` (Drill, Rubric, DrillTier), registry in `src/core/drills/registry.ts`.
Generator: `generateLeg(seed, profile)` / `generateStage(seed, profile)` in src/core/generator/generate.ts (`PROFILES` presets: pauseDrill, timedDrill, landmarkDrill, calibration, recovery, fullLeg, combo, fullStage; `GenProfile` knobs legs/cpCount, lineDensity, trapDensity, signals, trains, slowTraffic, calibration, lunchRestart, noPauseTraps, mix). Output passes `validateScenario` and `checkRouteExits`; `scenario.tags` carries truth flags (`trap:<id>:<n>`, `trap:missingPause:<n>`, `cp:cpN:afterManeuver:<kind>`, `train:<n>:hit|miss`).
Traps: `TRAPS`, `trapById`, `trapToNodeSpec(card, {speed})`, `trapDistractorBefore(card, rng)`, `trapCameo(card)` (SVG string), `mainRoadExit`, `exitForCallout`, `turnBand` in src/core/generator/traps.ts.

## V2 core additions (ENGINE_VERSION 2.0.0; see SPECS.md "V2")
Actions (all validated by `validateAction`; refusals never throw, they log `ta.refused` / driver messages):
- `ta.request {legIndex, seconds, fromLine, toLine, note?}`: per-leg Time Allowance at a TA point (a book row with `taPoint`) inside its window (`taPoint.windowSeconds`, 900); multiples of 10 s, max 1770; non-multiples are rounded against the team (below the midpoint of measured delay -> down, else up, reported in `sim.taRequests[i].adjustment` and as a driver message). `ta.declare {seconds, legIndex?}` is a deprecated alias (current leg at a TA point; books with no TA point keep the old anywhere-filing and credit). `scorecard.ack` at the end-of-stage TA point. `speed.emergency {mph}` / `speed.resume` (qualifying delay accrues only on trains, `accident` hazards, signals if `rules.taForSignals`, and emergency speed; never navigation errors or slow vehicles). `watch.mode {mode?}`, `watch.reset {force?}` (reset only while stopped unless forced), `clock.read`.
- Sim API: `sim.taState()` / `observe().ta` = {hasTaPoints, windowOpen, windowEndsTod, secondsLeft, endOfStage, eligibleLegs, requests, scorecardAcked, emergency}; `sim.taAdvice(leg)` = {measuredDelay, recoverable, possible, suggested (floor 10 s), fromLine, toLine}; `sim.taRequests`, `sim.taQualifying`, `sim.taRecoverable`; `sim.transitIn[n]`, `sim.transitOutFor(endIns)`, `sim.holdGoTod(node)` (restart time, exact-transit OUT, promoted-stop scheduled departure); `observe().asp/.timeZone`; `observe({peek:true, clock:true})` logs a clock read; `observe().stopwatch.{mode,lapTable,frozen,recalled}`.
- `StageResult` gains `dnf`, `ta {requests, scorecardAcked|null}`, `earlyDepartureMinutes`, `instrumentDiscipline [{kind: clockForTimeOfDay|clockForInterval|calibrationWithoutLap|lapWhileFrozen, line, text}]`, `instrumentLog`; `score` gains `dnf, dnfReason, earlyDepartures, earlyDeparturePenalty, observationPenalty, penaltyItems`; each leg gains `taReason, capped`.
- Scoring (src/core/scoring.ts): `rules.maxLate 120 / maxEarly 300 / missedCheckpoint 180 / observationMissPenalty 180 / earlyDepartureMinutes 5 / earlyDeparturePenalties [60,300] / splitHoldSeconds 5 / taMaxRequestSeconds 1770`; `rookieDropWorstLeg`, `maxPerCp` removed. `ageFactor(year)` is the printed table. `championshipTotal(stages:{stage, score}[], division = 'rookie', {year?})` -> {discarded, raw, afterDiscards, ageFactor, ageFactored, championshipEligible}; `DIVISION_DISCARDS`, `compareStandings`, `rankStandings`, `TIE_BREAK_ORDER`.
- Book fields on `Instruction`: `remark`, `baseTime`, `transit {exact, seconds, miles?, end?}`, `freeZone`, `endTimed`, `taPoint {windowSeconds, endOfStage}`, `promotedStop {kind, leaveBeforeEndSeconds}`, `calibrationStart`, `printed`, `omitted`; `TimedSegment.delayed`. `Scenario` gains `asp`, `baseStartTime`, `timeZone`, `bookStyle 'example'|'race'` (default from aids rung). `Hazard` gains `{kind:'accident', s, speedMph, lengthFt}`.
- GRIID helpers (src/core/griid.ts): `columnCLines(ins, timeZone)`, `columnBSymbols(ins)`, `transitMiles(ins)`, `odometerBox(ins)` ("0045"), `columnD(ins, style)`, `formatInterval`, `formatClockFace`; `describeInstruction(spec, node, ctx)` (GRIID-004 sentences); `instructionS(course, ins)` (GRIID-007 speed-change position).
- ScenarioBuilder: `start(speed?)`, `warmup()`, `calibrationRun({miles, speed, points, thenTransit})`, `transit({exact?, seconds, miles?})`, `endTransit({speed})`, `restart(speed, baseTod)` (= base + `asp` x 60), `freeZone()/endFreeZone()`, `endTimedPortion({endOfStage, transit})` (adds the TA point), `promotedStop(kind, leaveBefore)`, `observationFinish()`; options `asp, timeZone, bookStyle`. `build()` is pure.
- Generator: `GenProfile` gains `skeleton:'day'`, `pauseOnStopProbability`, `pauseOnSignalProbability`, `freeZoneProbability`, `endTimed`, `asp`, `timeZone`, `bookStyle`; speeds 20..55.
- Charts: `buildPerfTable(car)` -> `{accel, stopGo, turns: Matrix, stop, lead, turn}` (`Matrix = {speeds, rows[in][out]}`); `PACKARD_1936` (table-driven), `KNOWN_CARS`, `apexSpeed`, `matrixAt`, `speedChangeLoss`; `CarSpec.tables`, `CarSpec.turnZoneFt`. Calibration: `adjustFactor`, `timewiseAdjustment`, `clicksPerSecondPerHour`.
- Stopwatch: default kind is digital (`DEFAULT_WATCH`); `Stopwatch.{mode, setMode, toggleMode, lapTable, isFrozen, recall(now), reset(now, force)}`.
